# Tenzin Wangchu Khongsai — Personal Portfolio

A modern, high-performance, and visually captivating portfolio showcasing projects, engineering leadership, and creative direction.

🌐 **Live Website**: [https://portfolio-eta-bay-47.vercel.app](https://portfolio-eta-bay-47.vercel.app)

---

## ✨ Features

- **Cinematic Visuals & Animations**: Fluid micro-interactions and transitions powered by Framer Motion & GSAP.
- **Interactive 3D / Creative Graphics**: Built with Three.js and custom canvas shaders.
- **Responsive & Modern Design**: Clean glassmorphism, refined typography, and responsive layouts tailored for mobile, tablet, and desktop screens.
- **Project Showcases**: Interactive galleries highlighting key software engineering, AI, and design work.

---

## 🛠️ Tech Stack

- **Framework**: [React 19](https://react.dev/) + [Vite 8](https://vitejs.dev/)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/)
- **Motion & Graphics**: [Framer Motion](https://www.framer.com/motion/), [GSAP](https://gsap.com/), [Three.js](https://threejs.org/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Deployment**: [Vercel](https://vercel.com/)

## 🚀 Getting Started Locally

### Prerequisites
- Node.js (v18 or higher recommended)
- npm, pnpm, or yarn

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/TenzinWangchuKhongsai/Portfolio.git
   cd Portfolio
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```

4. Build for production:
   ```bash
   npm run build
   ```
